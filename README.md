# HTML, CSS & JavaScript Mini Projects

A collection of beginner-friendly front-end projects built with **HTML, CSS, and JavaScript**.

## Projects

| # | Project | Description |
|---|---|---|
| 1 | Periodic Table | CSS Grid-based periodic table demonstrating layout and styling. |
| 2 | Calendar | Interactive monthly calendar with previous/next month navigation and date selection. |
| 3 | Online Book Shop | Responsive bookstore portfolio with featured books, categories, cart counter, and newsletter form. |
| 4 | Form Validation | Registration form with client-side validation for name, email, phone, password, confirmation, and terms. |
| 5 | DOM Manipulation | Interactive examples of selecting, changing, creating, and removing DOM elements. |

## How to Run

1. Download or clone this repository.
2. Open any project folder.
3. Open `index.html` in your browser.

No framework, package manager, or server is required.
